## New Features

**Project export center with filtered CSV export**
Export project tasks to CSV directly from the task list with your current filters applied, or use the new Task Export tab in Project Settings to export tasks, comments, and files, together or separately.

**Mark time off and leave**
Business plan members can now mark specific dates as time off or leave, from Home > Calendar or the Quick Action button, so project managers see accurate availability in workload views.

## Improvements

- **Task dependencies visible on roadmap**: existing "Blocked by" dependencies now render directly on the Roadmap view instead of only the task list
- **Unified roadmap across all projects**: a cross-project timeline shows tasks from every project in one view, with in-place editing
- **Restrict task assignment by user role**: Business plan workspaces can limit task creation and assignment to Admins and Team Leads, at the project or organization level
- **Configure project details from templates**: creating a project from a template now prompts for name, dates, category, client, and project manager
- **Copy direct links to task comments**: each comment in the task drawer now has a copyable link that opens the task and scrolls to it
- **Auto-assign subtasks to parent phase**: new subtasks now inherit their parent task's phase automatically, controlled by a project setting
- **Subtasks now visible in Schedule**: subtasks with assigned members and scheduled dates now appear in the Schedule view alongside their parent tasks
- Time log entries in the recently logged list are now clickable and jump straight to the corresponding project's time log panel
- Custom fields can now be added directly from the task drawer, not just the task list
- Project phases now display in chronological order based on their start and end dates
- The Team Switcher dropdown now includes a search bar to find a team by name
