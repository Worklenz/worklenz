## New Features

**Bulk task assignment**
Select multiple tasks and assign them to a team member in one action. Works
in the task list and the Kanban board.

**Status filter in task list**
Filter the task list by one or more statuses. The filter updates the list
instantly — no Apply button needed.

## Bug Fixes

- Gantt export now includes subtask rows
- Fixed avatar upload cropping on Firefox

## Improvements

- Project list loads faster on large workspaces
